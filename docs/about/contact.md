To write to the people who run EELSdb, use the contact form. It emails every administrator, and a person replies to the address you give.

[Send us a message](/contact/)

The form asks for your name, your email address, what the message is about and the message. If you are signed in, your name and primary confirmed address are filled in. EELSdb does not send you a copy of your message. Messages are kept for a year.

## GitHub issues

For a bug report or a feature request that others may want to follow, open an issue on GitHub instead. It is public, so do not put private details in it.

[Open an issue on GitHub](https://github.com/ewels/EELSdb/issues)

The [moderators](/moderators/) check each submitted spectrum before it is published.
